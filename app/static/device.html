    Upload NAM (A2 Lite)

    Only the "lite" WaveNet tier this pedal actually runs is supported (1871 weights, one fixed architecture) — if your file is a SlimmableContainer (like NAM's own trainer produces), its lite submodel is picked automatically; a "full"-only file or a different lite architecture is rejected rather than guessed at. NAM's own writable range is slots 1-20 (narrower than SnapTone's full 1-100 catalog) — this overwrites whatever is currently in the chosen slot.

    Upload IR

    Sends the file's raw PCM straight to the pedal — no resampling or re-quantizing (that's exactly what Suite's own upload does too). Only the first ~46ms of the file fits in a slot; the rest is not sent. This overwrites whatever is currently in the chosen slot.

    Upload SnapTone (.clo)

    Uploads an already-built SnapTone/"Tone Catch" file verbatim: a real .clo file (the format Suite itself saves them in, starts with the bytes "VTSI") goes to a chosen library slot. To build one from a NAM model or from recordings, use the "Create SnapTone" sections. This overwrites whatever is currently in that slot, and other patches whose N→S module already points at it will change too.

    Create SnapTone from audio

    Builds a SnapTone from a recording of your amp: download the 70 s test signal with the button, play it through your amp, record what comes out from the very start of playback (same length, nothing trimmed), and pick the recording here. The algorithm: static waveshaper fit, two transfer-function passes, iterative min-phase IR design, spectral correction on the playing section. The finished SnapTone is sent to the chosen slot — this overwrites whatever is in it, and other patches pointing at that slot will change too. The test signal is generated by this page, so the result can differ slightly from a SnapTone made with Valeton Suite.

    Create SnapTone from a .nam file

    Builds a SnapTone from a NAM/Neural Amp Modeler file: the model's neural network (a WaveNet, computed here in the browser) is run on a 70 s test signal generated by this page, scaled and quantized, and the result goes through the amp profiler. The finished SnapTone is then sent to the chosen slot — this overwrites whatever is in it, and other patches pointing at that slot will change too. Supports 48 kHz models in the single-array shape this pedal's NAM slots use and the older multi-array "classic" shape; anything else is refused with a clear error. Results can differ slightly from a SnapTone made with Valeton Suite (about a dB in level and a couple of dB of ripple, mostly above 8 kHz).
